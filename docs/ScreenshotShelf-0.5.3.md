# ScreenshotShelf 0.5.3

## Correcciones y cambios

- Corrige el temporizador de guardado y cierre automático.
- El temporizador ya no se pausa al colocar el cursor sobre la miniatura.
- El valor escrito en segundos se guarda también al salir del campo, sin exigir
  que se pulse Enter.
- Añade “No mostrar miniatura al copiar automáticamente”.
- Cuando se oculta la miniatura, la captura se copia y se guarda directamente
  en la ubicación predeterminada.
- Si el guardado silencioso falla, muestra la miniatura para evitar perder la
  captura.

## Versión

- Marketing version: `0.5.3`
- Build: `21`
