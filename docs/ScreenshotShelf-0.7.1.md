# ScreenshotShelf 0.7.1

## Corrección

- Sustituye el event tap de Accesibilidad por un hotkey global de Carbon.
- `⌘⇧5` funciona sin permiso de Accesibilidad una vez desactivado el atajo
  equivalente de Apple.
- Registra en el log cualquier fallo al instalar el atajo.
- El menú superior indica si el atajo quedó registrado o no está disponible.
