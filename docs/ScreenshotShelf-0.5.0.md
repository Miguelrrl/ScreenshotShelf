# ScreenshotShelf 0.5.0

## Cambios

- Añade una ventana de Ajustes desde el menú superior.
- Permite elegir la ubicación predeterminada de las capturas.
- Permite mantener las miniaturas indefinidamente o cerrarlas automáticamente.
- El tiempo de cierre automático se configura entre 1 y 3600 segundos.
- El temporizador se pausa mientras el cursor está sobre la miniatura.
- Antes de desaparecer, la captura se guarda en la ubicación predeterminada.

## Versión

- Marketing version: `0.5.0`
- Build: `18`
