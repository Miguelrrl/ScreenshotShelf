# ScreenshotShelf 0.4.0

## Cambios

- Añade controles para acercar, alejar y ajustar la captura a la ventana.
- Mantiene el zoom con gesto de trackpad.
- Permite seleccionar y arrastrar texto insertado.
- Incorpora OCR local mediante Apple Vision.
- Copia al portapapeles el texto detectado y permite revisarlo.

## Privacidad

El reconocimiento se ejecuta localmente en la Mac. La captura no se envía a
servicios externos.

## Versión

- Marketing version: `0.4.0`
- Build: `13`
