# ScreenshotShelf 0.7.3

- Conserva una identidad de firma estable para que el permiso de grabación no
  cambie en cada actualización.
- Recuerda la última región seleccionada para grabar.
- La primera grabación muestra una región centrada por defecto.
- La región puede moverse y redimensionarse arrastrando sus bordes.

## Versión

- Marketing version: `0.7.3`
- Build: `26`
