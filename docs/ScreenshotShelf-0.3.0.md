# ScreenshotShelf 0.3.0

## Cambios

- Editor de capturas completamente nativo en AppKit.
- Herramientas de lápiz, flecha, rectángulo, círculo, texto y recorte.
- Selector de color y control de grosor.
- Deshacer, rehacer y restablecer.
- Acciones `Aplicar` y `Cancelar`.
- La miniatura se actualiza después de aplicar la edición.
- Preview deja de utilizarse para editar.

## Versión

- Marketing version: `0.3.0`
- Build: `10`
